# 🎬 Sentiment Analysis using RNN (IMDB Movie Reviews)

This project implements a Recurrent Neural Network (RNN) to perform sentiment analysis on IMDB movie reviews, classifying them as positive or negative.

---

## 📖 Project Overview:

Sentiment analysis is a Natural Language Processing (NLP) task used to determine the emotional tone behind text data.

In this project, an RNN model is trained on the IMDB dataset to understand and classify movie reviews based on their sentiment.

---

## 📂 Dataset:

- **IMDB Movie Reviews Dataset**
  - 50,000 reviews (split into training & testing)
  - Binary sentiment classification (Positive / Negative)

---

## 🛠️ Technologies Used:

- Python 🐍
- TensorFlow / Keras
- NumPy
- Matplotlib

---

## 🧩 Model Architecture:

The model consists of:

- Embedding Layer (for text representation)
- Recurrent Neural Network (RNN / LSTM)
- Dense Layers
- Output Layer (Sigmoid activation)

---

## ⚙️ Workflow:

1. Import libraries
2. Load IMDB dataset
3. Preprocess text data (tokenization & padding)
4. Build RNN model
5. Compile the model
6. Train the model
7. Evaluate performance
8. Predict sentiment

---

## 📊 Results:

- The model successfully classifies movie reviews as positive or negative.
- Achieves good accuracy on unseen test data.
